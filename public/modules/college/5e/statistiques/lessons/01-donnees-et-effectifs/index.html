Organiser des Données

Découvrez comment transformer une liste désordonnée en un tableau d'effectifs clair et lisible.

1

🎮 Le Trieur de Données

💡 Comment utiliser cet outil ?

Action : Cliquez sur chaque fruit de la série brute (le bazar !) pour le ranger dans le tableau des effectifs.

Objectif : Comprendre que l'effectif est simplement le nombre de fois où une valeur apparaît. L'effectif total est la somme de tous les effectifs.

2

Vocabulaire des Statistiques

• Effectif d'une valeur : C'est le nombre de fois où cette valeur apparaît dans la série brute.
• Effectif Total : C'est le nombre total d'individus ou de données (la somme de tous les effectifs).
3

Test de Dénombrement

Dans la classe, les notes obtenues sont : 12, 15, 12, 8, 15, 12, 18, 8. Quel est l'effectif de la note 12 ?
