Introduction aux fonctions

Découvrez ce qu'est une fonction : la fameuse "machine mathématique".

1

La machine mathématique

Une fonction $f$ est comme une machine. On y fait entrer un nombre $x$, la machine fait un calcul, et ressort un nouveau nombre appelé $f(x)$.

$x$
Antécédent
➔
Fonction $f$
ex: multiplier par 2
➔
$f(x)$
Image

Si $f(x) = 2x$, alors pour $x = 3$, on aura $f(3) = 2 \times 3 = 6$.
L'image de 3 est 6. L'antécédent de 6 est 3.
